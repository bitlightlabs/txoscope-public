# Security Policy

## Reporting

Do **not** open a public GitHub issue for security reports.

Please report vulnerabilities privately to Bitlight Labs at [info@bitlightlabs.com](mailto:info@bitlightlabs.com).

Please include:

- A description of the issue and its impact
- Steps to reproduce, or a minimal test case
- Affected crate(s), versions, or commit SHAs if known
